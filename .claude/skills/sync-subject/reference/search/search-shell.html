How it works

What this index is, and is not

Every entry here is lifted unedited from a published week page — the Key concepts glossary, the Acronyms and Formulas tabs, and the flashcard deck. A term that appears in more than one week is shown once, with each week’s definition beneath it, so you can see how the idea develops across the subject. Nothing is written for this page: if a definition is wrong here it is wrong on the week page too, and that is where it gets fixed.
